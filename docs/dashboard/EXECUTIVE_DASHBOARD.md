## The footnotes the steering committee requested be shortened

1. **All values are invented illustrative numbers** and should never be presented as actual telemetry.
2. A zero-response survey does not yield a mathematically defined satisfaction percentage.
3. A Kubernetes restart does not necessarily mean successful recovery.
4. The project is a satirical Python example, not an online service with customers.
5. Governance compliance remains unverified. Green is a colour, not evidence.
